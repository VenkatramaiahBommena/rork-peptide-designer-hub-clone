# PeptiForge — Peptide Sequence Generator & Docking Platform


## PeptiForge: A Peptide Engineering Web Platform

### Features
- **Peptide Generator**: Input therapeutic targets (diabetic, PDC, antifungal, etc.) and generate optimized peptide sequences with unnatural amino acid support
- **Docking Score Engine**: Built-in scoring model that evaluates peptide-target binding compatibility, with tweakable scoring parameters for fine-tuning results
- **Sequence Alignment Viewer**: Interactive visualization showing sequence alignments with color-coded residue matches, gaps, and mutations
- **CSV Export**: One-click export of generated sequences, docking scores, and alignment data to CSV files for offline analysis
- **User Authentication**: Secure sign-up and login with protected user dashboards
- **Backend API**: Persistent storage for all generated peptides, docking results, and alignment data
- **Activity Profile**: Track user's generation history, favorite sequences, and usage statistics
- **Downloadable Package**: ZIP download of the complete platform for offline use

### Design
- Dark, scientific theme with deep navy and teal accents — inspired by molecular visualization tools
- Clean card-based layout with subtle grid backgrounds evoking protein structures
- Smooth transitions and hover effects on interactive elements
- Professional typography optimized for displaying amino acid sequences (monospace for sequence data)

### Pages / Screens
- **Landing Page**: Hero section explaining the platform with quick-start input field for peptide generation
- **Generator Dashboard**: Input form with therapeutic target selection, unnatural amino acid picker, and docking parameter sliders
- **Results View**: Generated peptide sequences displayed in cards with docking scores, sortable and filterable
- **Alignment Viewer**: Interactive sequence alignment visualization with zoom and scroll
- **User Auth Pages**: Login and registration with email/password
- **User Profile**: Activity history, saved sequences, export history, and usage stats
- **API Documentation**: Documentation page for the backend API endpoints

### App Icon
- A stylized peptide helix motif with teal and deep navy gradient, featuring a molecular bond pattern and the letter "P" integrated into the helix structure
